Functions

Functions are reusable blocks of code that perform a specific task. They help in organizing code, making it more readable, and reducing redundancy. Functions can take inputs, called parameters, and can return outputs.

Defining a Function

Functions are defined using the function keyword followed by a name and a list of parameters in parentheses. The body of the function is enclosed in curly brackets.

Calling a Function

Functions can be called by using their name followed by a list of arguments in parentheses. The arguments are passed to the function and used to perform the task.
